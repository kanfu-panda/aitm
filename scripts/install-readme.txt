aitm 安装说明
============

1) 把 aitm 图标拖到右边的 Applications 文件夹

2) 第一次双击 aitm 时如果提示"无法打开 aitm，因为无法验证开发者"：

   方法 A（推荐，一次性解决）
   ——————————————————————
   打开 Terminal（启动台 → 其他 → 终端），粘贴下面这行命令回车：

     xattr -cr /Applications/aitm.app

   然后再双击 aitm 即可。

   方法 B（图形界面）
   ——————————————————
   系统设置 → 隐私与安全性 → 下滑到底，看到"已阻止 aitm.app"
   → 点旁边的"仍要打开"。

3) 之后正常使用，不再有警告。

————————————————————————————————————————————

为什么会有这个提示？
aitm 没有付费做 Apple 官方签名（每年 $99 开发者订阅）。
代码完全开源，无后台联网，可放心使用。
